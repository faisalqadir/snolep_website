# Snolep Technologies website

Live at **https://faisalqadir.github.io/snolep_website/** (GitHub Pages, deployed from `main`, root).

The Snolep logo's snow leopard dissolves into dots that leap off it as a dotted snow leopard, bound
from principle to principle, pour through an hourglass beside the project cards, and land on the
call to action, where they become the dotted SNOLEP TECHNOLOGIES.

- `index.html` — the page (styles, copy, cursor, and the story's keyframes).
- `js/dot-story.js`, `js/scroll-3d-hero.js` — the dot runtime (from the scroll-3d-hero skill).
- `models/snow-leopard.glb` — the snow leopard, generated by `tools/snow-leopard.py`
  (`python3 tools/snow-leopard.py models/snow-leopard.glb`; needs numpy, scikit-image, pyfqmr).
- `img/` — the logo, cut into the leopard and the lettering.

Project cards and the contact address (`#cta-link`) are placeholders.

To run it locally, serve the folder (ES modules don't load from `file://`), e.g. `npx serve .`.
Add `?dots-debug` to the URL for the story's debug overlay.
